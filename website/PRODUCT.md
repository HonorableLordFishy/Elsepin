# Elsepin website

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product purpose

Help visitors understand Elsepin's iPhone location simulation, explore its
appearance, and find the verified release and setup instructions. The website is
not a location engine. The native app remains outside this workstream.

## Confirmed constraints

The owner's brief retains the lightweight HTML/CSS/JavaScript and Python export,
approved icon artwork, native theme data, setup limitations, privacy accuracy,
keyboard access, normal scrolling, reduced motion, and narrow/enlarged-text use.
Keep the work local: no push, deployment, or IPA work is authorized here.

## Brand commitments

Elsepin, Prism Jumpgate, eight native themes, thirteen approved icon choices.
The owner rejected the cream editorial refinement and explicitly requested a full
rewrite with scroll animations, a better map, liquid-glass design, and a preview
action that visibly works. This supersedes preserving the old website's look.

## Evidence

Current source and public release were verified in this session. See README.md
for source-of-truth paths. Current source is 2.6.1 build 84 development; public
release.json independently records the verified public 2.6.0 release. The current
native screenshots are simulator fixtures with test banners; don't silently
present them as release screenshots. Preserve an explicitly illustrated web demo.

## Open decisions

No new pricing, compatibility guarantees, audience demographics, testimonials,
or publication approval were supplied; do not invent them.
