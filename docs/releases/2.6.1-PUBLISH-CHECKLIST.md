# Elsepin 2.6.1 publication handoff

Prepared 15 November 2026. This file is private maintainer guidance, not a release approval.

## Prepared

- Public 2.6.0 remains latest. 2.6.1 notes cover test builds 60–86.
- Source repo is private; Elsepin-Releases remains public for docs and downloads.
- Public introduction, setup, full changelog, build register and feature summary are updated.
- Existing experimental helpers remain in build 86. Their removal and the new Life360 feature are deferred; official access first, private helper last.
- Native/package evidence for build 86 is in `.build/artifacts/build86/`. No code or IPA changed during documentation preparation.

## Before publication

1. Record the owner's final physical-iPhone outcome: pairing/retry, real movement, Pause/Stop/clear, VPN interruption/recovery and the latest map-visibility behavior. Keep any reported failure open.
2. Prepare an official-channel package following `docs/UPDATES.md`. Build 86 currently has `SHIFT_RELEASE_CHANNEL=prerelease`; do not relabel its binary as stable. Check private Mac allowance first, preserve the GitLab fallback, and do not enable paid billing. A metadata-only stable package still needs package verification and a short install/launch/Stop check.
3. Attach only the verified release IPA to the existing 2.6.1 draft; update the notes with its actual version/build and final test result. Keep the draft unpublished until explicit publication approval. Do not promote simulator success into proof of real spoofing.
4. On approval, publish numeric tag `v2.6.1` as a non-prerelease official release and verify `/releases/latest`. Then update public README status, release notes and `website/release.json` to the actual published artifact. Follow the website publication workflow separately.

Do not publish or package merely because a README or draft is ready. Keep the existing device pairing, install identifiers, backups and library data unchanged.
